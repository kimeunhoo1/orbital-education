# 🌟 오비탈 (Orbital) - 수과학 교육 플랫폼

프라이빗 노트 같은 수과학 교육 웹사이트입니다.

## 📋 주요 기능

### 1. 인증 시스템
- ✅ 회원가입 / 로그인
- ✅ 관리자 계정 (ID: admin1234, PW: admin1234)
- ✅ 실시간 데이터베이스 저장

### 2. 테스트룸
- 📝 모의고사 검색
- 📊 나의 모의고사 (결제 승인 후)
- 💳 계좌이체 결제 시스템
- 📄 PDF 파일 관리
- 📅 시험일/답안지 공개일 설정

### 3. 강의실
- 🎥 실시간 화상 라이브 강의
- 💬 실시간 채팅
- 🖥️ 화면 공유
- 🎓 소회의실 기능
- 📹 라이브 다시보기

### 4. 동영상강의
- 📚 지난 강의 아카이빙 (라이브 종료 1개월 후)
- 📂 강의 자료 다운로드

### 5. 블로그
- ✍️ 관리자 글 작성
- 💬 사용자 댓글
- 😊 이모티콘 반응
- 📎 파일 첨부

### 6. 관리자 대시보드
- 📊 모의고사 관리
- 💰 결제 승인
- 📢 팝업 관리
- 👥 사용자 관리

## 🛠️ 기술 스택

- **Frontend**: React.js, Tailwind CSS, Redux
- **Backend**: Node.js, Express.js
- **Database**: Firebase Realtime Database
- **Real-time**: WebSocket, Socket.io
- **Video**: Jitsi Meet 통합
- **Payment**: 토스페이먼츠 API

## 🚀 빠른 시작

### 프론트엔드
```bash
cd frontend
npm install
npm start
```

### 백엔드
```bash
cd backend
npm install
npm start
```
